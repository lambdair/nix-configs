# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Multi-platform Nix configuration repository managing NixOS, nix-darwin (macOS), and home-manager environments via flakes. Uses nixpkgs-unstable channel.

## Common Commands

All commands are defined in `justfile`:

```bash
just check              # Validate flake (nix flake check)
just fmt                # Format all Nix files (nixfmt-tree)
just home-linux         # Apply Linux home-manager config (NixHome)
just home-mac           # Apply macOS home-manager config (MacHome)
just system-nixos       # Apply NixOS system config
just system-darwin      # Apply macOS system config
just system-wsl         # Apply WSL system config
just update             # Update all flake inputs
just update-input NAME  # Update specific flake input
just fetch              # Run nvfetcher to update _sources/
```

After editing Nix files, run `just check` to validate. Run `just fmt` before finalizing changes.

## Architecture

### Flake Outputs

| Output | System | Description |
|--------|--------|-------------|
| `nixosConfigurations.NixOS` | x86_64-linux | Primary NixOS (host: daiquiri) |
| `nixosConfigurations.WSL` | x86_64-linux | WSL environment (host: sol-cubano) |
| `darwinConfigurations.MacOS` | aarch64-darwin | macOS (host: sonora) |
| `homeConfigurations.NixHome` | x86_64-linux | Linux home-manager |
| `homeConfigurations.MacHome` | aarch64-darwin | macOS home-manager |

### Directory Layout

- **`flake.nix`** — Entry point defining all inputs, system configs, home configs, devShell, and formatter
- **`host/`** — System-level (NixOS/nix-darwin) configurations
  - `base.nix` — Shared base config (nix settings, user account, gc)
  - `font.nix` — Font packages and fontconfig (CJK, Nerd Fonts, APL/BQN/Uiua fonts)
  - `daiquiri/` — NixOS: systemd-boot, niri Wayland compositor, fcitx5 IME, greetd
  - `sol-cubano/` — WSL-specific config
  - `sonora/` — macOS/nix-darwin config (includes private module)
- **`home/`** — Home-manager configurations
  - `default.nix` — Core: 200+ packages, custom derivations (budget_tracker_tui, heptabase), runtime libraries
  - `linux/` — Linux-specific home config (Wayland desktop apps)
  - `mac/` — macOS-specific home config
  - `emacs/` — Emacs config with 100+ packages (uses emacs-overlay)
  - `nvim/` — Neovim config via nixvim framework
  - `helix.nix` — Helix editor with custom LSP configurations
  - `claude/` — Claude Code settings, hooks, and personal preference docs
  - `difit.nix` — Custom TypeScript/PNPM package derivation
- **`overlays/`** — Custom overlays (e.g., uiua386 font monospace fix)
- **`_sources/`** — Auto-generated by nvfetcher; do not edit manually
- **`nvfetcher.toml`** — Defines external source tracking (Emacs/Neovim plugins, tools, fonts)

### Key Patterns

- **`sources` parameter**: Custom packages in `home/default.nix` use `sources` (from `_sources/generated.nix` via nvfetcher) for upstream version tracking
- **Platform conditionals**: `pkgs.stdenv.isLinux` / `stdenv.isDarwin` for platform-specific packages
- **Overlays**: Applied per-platform in flake.nix (rust-overlay, emacs-overlay always; uiua386 fix on macOS only)
- **Private module**: `inputs.private` from git.sr.ht provides sensitive configs (darwinModules, homeModules)
- **nixvim**: Neovim is configured declaratively via the nixvim home module, not raw Lua/vim files
- **catppuccin**: Theme module integrated into home-manager for consistent theming

### Adding External Packages

1. Add source definition to `nvfetcher.toml`
2. Run `just fetch` to regenerate `_sources/generated.nix`
3. Reference via `sources.<name>` in Nix expressions

## Nix Style

- Formatter: `nixfmt` (the official Nix formatter, not nixfmt-classic)
- Follow existing patterns for new modules — check similar files first
- `allowUnfree = true` is set globally
