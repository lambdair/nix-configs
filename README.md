# nix-configs

Nix flake configuring three machines and their user environments — NixOS,
macOS through nix-darwin, and WSL — from one nixpkgs-unstable tree.

## Configurations

| Output | System | Host |
|---|---|---|
| `nixosConfigurations.NixOS` | x86_64-linux | daiquiri |
| `nixosConfigurations.WSL` | x86_64-linux | sol-cubano |
| `darwinConfigurations.MacOS` | aarch64-darwin | sonora |
| `homeConfigurations.NixHome` | x86_64-linux | — |
| `homeConfigurations.WSLHome` | x86_64-linux | — |
| `homeConfigurations.MacHome` | aarch64-darwin | — |
| `packages.<system>.ci-heavy` | both | the expensive builds, aggregated for CI |

## Layout

- `host/` — system configuration: shared base, fonts, and one directory per host
- `home/` — home-manager: packages, Emacs, Neovim, Helix, and the Claude Code setup
- `pkgs/` — derivations for what nixpkgs does not carry, shared with `ci-heavy`
- `overlays/` — fixes and pins for packages broken on unstable
- `scripts/` — maintenance run through `just`
- `_sources/` — generated by nvfetcher from `nvfetcher.toml`; not edited by hand

## Usage

Everything goes through `just`; run it with no arguments for the full list.

```
just check              # validate the flake
just fmt                # format with nixfmt
just home-mac           # apply the macOS home-manager configuration
just system-nixos       # apply the NixOS system configuration
just update             # update every flake input
just fetch              # regenerate _sources/ with nvfetcher
```

## Notes

**This repository does not build as-is for anyone else.** `flake.nix` takes a
`private` input from a repository that is not public, and the macOS and
home-manager configurations import modules from it. The pieces worth borrowing
are the individual modules under `home/`, `host/`, and `pkgs/`, not the flake as
a whole.

The expensive derivations are built by GitHub Actions and pushed to
`lambdair.cachix.org`; `host/cache.nix` lists it as a substituter.

`CLAUDE.md` describes the same layout for Claude Code, and carries the
conventions this repository follows.
